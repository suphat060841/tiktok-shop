> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add Session Analytics, Gemini AI FAQ fallback, and Flash Sale Timer to TikTok Live AI Smart Selling Studio.

**Architecture:** All three features extend `server.js` with new manager classes, new REST/Socket.IO endpoints, and new UI panels in `index.html`/`app.js`. The stream overlay gains a Flash Sale countdown banner. No new external services are required for Phase 1 (Analytics + Flash Sale); Phase 2 (Gemini) requires `@google/genai` and a `.env` API key.

**Tech Stack:** Node.js 26 ESM, Express, Socket.IO, Vanilla JS, @google/genai (Phase 2 only)

**Spec:** `C:\Users\BINARY\.gemini\antigravity\brain\b23d930e-64df-4554-8552-fcfb7d3eaf71\v4-feature-design.md`

## Global Constraints

- ESM only (`"type":"module"` in package.json) — no `require()`, use `import`
- All new classes go in `server.js` and are exported at the bottom
- No emoji in TTS speech strings (TTS reads emoji aloud in Thai)
- `data/sessions/` directory must be created if not exists before writing
- Test runner: `node verify_system.mjs` — must end 45+ PASSED, 0 FAILED after each task
- Python process must NOT be spawned in tests — use exported module directly
- No `.env` file exists yet — create it in Phase 2 only

## Review Focus

- **Empty order list on session start:** `SessionTracker.getStats()` must return zero counts, not throw when no orders recorded yet
- **Flash Sale stop mid-interval:** stopping timer must cancel pending speech alerts and emit `flash_sale_stopped` before the next tick fires
- **Gemini API key missing/invalid at runtime:** `processComment()` must fall through to general reply gracefully when Gemini call throws — never crash the server
- **Concurrent Flash Sales:** starting a new Flash Sale while one is active must stop the previous one cleanly (no duplicate `setInterval`)
- **Order keyword false-positive:** comment "ไม่สั่ง" contains "สั่ง" — order detection must check for negation prefix "ไม่" before counting

  Add `function detectOrderIntent(comment)` that returns `true` when comment contains an order keyword but does NOT start with a negation prefix. Place before `class AIBrain`.

  ```js
  const ORDER_KEYWORDS = ['กด','สั่ง','โอน','ซื้อ','จ่าย','จอง','เอา','ขอ','1ชิ้น','2ชิ้น','3ชิ้น'];
  const NEGATION_PREFIXES = ['ไม่','ยัง','ยังไม่'];
  function detectOrderIntent(comment) {
    const c = comment.toLowerCase();
    if (NEGATION_PREFIXES.some(n => c.startsWith(n))) return false;
    return ORDER_KEYWORDS.some(k => c.includes(k));
  }
  ```

  ```js
  class FlashSaleManager {
    constructor() {
      this.active = false;
      this.remainingSeconds = 0;
      this.totalSeconds = 0;
      this.productId = null;
      this._interval = null;
    }
    start(durationMinutes, productId) {
      this.stop(); // clear any existing
      this.active = true;
      this.productId = productId;
      this.totalSeconds = durationMinutes * 60;
      this.remainingSeconds = this.totalSeconds;
      // Speak start alert, set interval tick, schedule half/60s/end alerts
    }
    stop() {
      if (this._interval) { clearInterval(this._interval); this._interval = null; }
      this.active = false;
      if (io) io.emit('flash_sale_stopped', {});
    }
    getState() {
      return { active: this.active, remainingSeconds: this.remainingSeconds,
               totalSeconds: this.totalSeconds, productId: this.productId };
    }
  }
  ```
