# 🛍️ TikTok Live AI - Smart Selling Studio (v3.0.0)

ระบบผู้ช่วยไลฟ์สดและแม่ค้า AI ขายของอัตโนมัติบน TikTok Shop / OBS Studio พัฒนาทดแทนโปรแกรม BocaLive เต็มรูปแบบ โดยไม่ต้องเสียค่าบริการรายเดือนและไม่ต้องติดตั้ง Virtual Camera Driver เพิ่มเติม

---

## 🌟 ฟังก์ชันหลักที่ถอดแบบและอัปเกรดจาก BocaLive

1. **Avatar แม่ค้าสาวไทยคนเดิม (Thai Presenter Model 1):**
   - ภาพลักษณ์สาวไทย สวมเสื้อเบลเซอร์สีเบจ รอยยิ้มจริงใจ ยกมือไหว้ทักทาย
   - **ระบบกะพริบตาเป็นธรรมชาติ (Organic Blink Engine):** กะพริบตานุ่มนวล 140ms ทุกๆ 3.2 - 5.8 วินาที
   - **ระบบขยับปากและท่าทางตามจังหวะพยางค์ (Syllable Cadence):** คำนวณความถี่จังหวะพยางค์ภาษาไทย 3.8Hz ผสานกับการผ่อนคลายคำ 1.9Hz ขยับเป็นธรรมชาติ ไม่ลอย
   - **Dual-Layer Morph Crossfade 60 FPS:** เรนเดอร์บน Canvas แบบเนียนนุ่ม ไม่กระตุก ใช้พลังงานเครื่องน้อยมาก

2. **Smart Director (ผู้กำกับห้องไลฟ์อัตโนมัติ):**
   - **ต้อนรับผู้ชมเข้าห้อง:** ทักทายคนดูใหม่แบบสุ่มเพื่อเปิดการมีส่วนร่วม
   - **ระบบตอบคำถามอัตโนมัติ (FAQ Keyword Matching):** ดักจับคำถามยอดฮิต (ส่งของกี่วัน, เก็บเงินปลายทาง, เปลี่ยนไซส์, ของแท้ไหม ฯลฯ) แล้วส่งให้แม่ค้า AI ตอบทันที
   - **ระบบเสียงมิกเซอร์ 3 ช่องทาง (tts_mixer.py):**
     - ช่องเสียงพูด (Voice Channel): Microsoft Edge-TTS ภาษาไทยคุณภาพสูง (`PremwadeeNeural` / `NiwatNeural`) พร้อมระบบแคชเสียงประหยัดเวลา
     - ช่องเสียงเอฟเฟกต์ (SFX Channel): เสียงกระดิ่ง, เสียงเหรียญตังค์, เสียงเฮ, เสียงกระดิ่งปิดการขาย
     - ช่องเสียงเพลงพื้นหลัง (BGM Channel): พร้อมระบบ **Auto-Ducking** หรี่เสียงเพลงอัตโนมัติเมื่อแม่ค้ากำลังพูด และคืนระดับเสียงเดิมเมื่อพูดจบ

3. **Product Spotlight & Promotion:**
   - ปักหมุดตะกร้าสินค้าแบบ Real-time พร้อมแสดงเลขตะกร้า, รูปภาพ, ราคาปกติ, ราคาโปรโมชั่น และสต็อกคงเหลือ
   - ระบบเร่งการตัดสินใจซื้อ (Urgency Alert): แจ้งเตือนของใกล้หมด หรือโปรโมชั่นนาทีทอง

4. **Gift & Confetti Celebration:**
   - แอนิเมชันป๊อปอัปแจ้งเตือนขอบคุณเมื่อได้รับของขวัญ พร้อมเอฟเฟกต์พลุกระดาษ Confetti หลากสีสันตระการตา

## 🚀 วิธีการเริ่มต้นใช้งาน (Quick Start)

### วิธีที่ 1: ดับเบิ้ลคลิกไฟล์เดียว (ง่ายที่สุด)
ดับเบิ้ลคลิกที่ไฟล์ **`START_SYSTEM.bat`** ในโฟลเดอร์นี้ ระบบจะรันเซิร์ฟเวอร์และเปิดหน้า Dashboard ในเว็บเบราว์เซอร์ให้อัตโนมัติ

### วิธีที่ 2: รันผ่าน Terminal / PowerShell
```bash
cd "e:\TikTok Shop\tiktok-live-ai"
node server.js
```

## 📺 การเชื่อมต่อกับ OBS Studio หรือ TikTok Live Studio

1. เปิดโปรแกรม **OBS Studio** หรือ **TikTok Live Studio**
2. ในส่วน **Sources** กดปุ่ม **+** แล้วเลือก **Browser (เบราว์เซอร์)**
3. ตั้งค่าดังนี้:
   - **URL:** `http://localhost:3000/stream-overlay`
   - **Width:** `1080`
   - **Height:** `1920`
   - ทำเครื่องหมายถูกที่ **Control audio via OBS** (หากต้องการคุมเสียงใน OBS)
4. กด **OK** ภาพแม่ค้า AI ขนาด 9:16 แนวตั้ง พร้อมป้ายปักหมุดสินค้าและแอนิเมชันจะปรากฏบนจอไลฟ์สดทันที!

## 🎛️ แดชบอร์ดควบคุม (Studio Dashboard)
เข้าใช้งานผ่านเบราว์เซอร์ที่: **`http://localhost:3000`**

- **ปุ่มเชื่อมต่อ TikTok:** ใส่ชื่อบัญชี `@tiktok_id` เพื่อเชื่อมต่อห้องไลฟ์จริง
- **แผงจำลองเหตุการณ์ (Simulation Sandbox):** สำหรับทดสอบระบบก่อนเริ่มไลฟ์จริง เช่น กดจำลองคนถาม, จำลองส่งของขวัญ, จำลองคนเข้าห้อง
- **One-Click Script Generator:** กดปุ่มสร้างสคริปต์เสนอขายสินค้าตะกร้าที่เลือก แม่ค้า AI จะเริ่มพรีเซนต์สินค้าทันที
- **จัดการสินค้า & กฎ FAQ:** เพิ่ม/แก้ไข รายการสินค้า ตะกร้า โปรโมชั่น และคีย์เวิร์ดตอบคำถามได้ตามต้องการ
